# مُحاور (Muhawir)

مساعد حواري عربي يجيب عن أسئلة التعريف بالإسلام وأساسيات الفقه والعقيدة **من مصادر معتمدة فقط**، ويعرض مع كل إجابة بطاقة مصدر، ويمتنع أو يحيل إلى المختص عندما لا تتوافر مرجعية كافية.

مشروع في **تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي**، المسار الأول: الحوار المعرفي والإجابات الموثوقة.

> **الحالة:** مرحلة التحضير والهيكل الأولي. بدأ تطوير الهيكل قبل 4 أكتوبر 2026 (بدء التحدي) بحسب إفادة المشارك عن الجلسة الافتتاحية، وما كُتب قبل الموعد مُفصَح عنه في [docs/BASELINE.md](docs/BASELINE.md). لا نصوص دينية حقيقية في المستودع بعد.

## معيار نجاح المسار

هل يقدم الحل إجابة صحيحة وواضحة ومناسبة للسائل، يمكن تتبعها إلى مصدر معتمد، ويمتنع أو يحيل إلى المختص عندما لا تتوافر مرجعية كافية؟ طريقة القياس في [EVALUATION.md](EVALUATION.md).

## ما يميّز الحل (مخطط له)

- إجابة قصيرة مسندة، تتبعها بطاقة مصدر: النص الأصلي المختصر واسم المصدر ومستواه ومكانه.
- مستويات المحتوى (أ إلى د) كما في الحزمة العلمية للتحدي، والامتناع أو الإحالة في المسائل الخلافية الحساسة والفتاوى الشخصية.
- يختار المستخدم اللغة وأسلوب الشرح (للصغار، للشباب، موسّع). الحقيقة الشرعية ثابتة والأسلوب هو ما يتغير.
- لا يخمّن النظام دين المستخدم أو خلفيته ولا يجمع بيانات شخصية.

## الرابط الحي والتشغيل

الرابط الحي: يُضاف بعد اختيار الاستضافة (القرار D2).

**الحالة الحالية:** الهيكل يعمل على **بيانات تجريبية مصطنعة** (`data/synthetic_corpus.json`) وليست نصوصًا دينية، وبلا نموذج لغوي: المولّد الحالي يقتبس المقاطع حرفيًا. نصوص المصادر المعتمدة تنتظر القرار D4، والنموذج ينتظر القرار D1.

التشغيل محليًا (Python 3.11 أو أحدث):

```bash
pip install -r requirements.txt
uvicorn muhawir.server:app --port 8000
# ثم افتح http://localhost:8000
```

الاختبارات:

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

بيانات المصادر (القرآن وموضوعات الآيات وتفسير الطبري وكتاب «المحرر في أسباب نزول القرآن» من الموسوعة القرآنية quranpedia.net) تُبنى في قاعدة SQLite عند النشر، ولا تُحفظ في المستودع:

```bash
python -m muhawir.build_data --download          # ينزّل الملفات ويبني data/muhawir.db
# أو إن كانت الملفات منزّلة: python -m muhawir.build_data --from-dir data/dumps
uvicorn muhawir.server:app --port 8000           # يستعمل data/muhawir.db تلقائيًا إن وُجدت
```

البناء يستغرق نحو 15 ثانية، والخادم يستهلك ذاكرة قليلة لأن البحث يجري من القرص (SQLite FTS5). أسماء الموضوعات تُستعمل في البحث فقط، والنص المعروض في بطاقة المصدر هو نص المصدر حرفيًا.

**النشر على Render (رابط التجربة):** الملف `render.yaml` يصف الخدمة كاملة: خطة مدفوعة ثابتة السعر لا تنام (`0.5c-512mb`)، وأمر البناء `pip install -r requirements.txt && python -m muhawir.build_data --download` الذي ينزّل المصادر ويبني قاعدة البيانات (نحو 300 ميغابايت ذاكرة في الذروة)، وأمر التشغيل `uvicorn muhawir.server:app --host 0.0.0.0 --port $PORT`، وفحص الحالة `/api/health`. الخطوات: في Render اختر New ثم Blueprint، واربط هذا المستودع، وأدخل مفتاح `ANTHROPIC_API_KEY` حين يُطلب (يُحفظ في إعدادات Render لا في المستودع). إن تعذّر الوصول إلى النموذج يقول مُحاور صراحة إن الخدمة غير متاحة مؤقتًا، ولا يعرض ذلك على أنه «لم أجد في المصادر».

**على أي استضافة أخرى:** أمرا البناء والتشغيل نفساهما، والمتغيرات `LLM_PROVIDER=model` و`ANTHROPIC_API_KEY` في إعدادات الاستضافة لا في المستودع.

وضع النموذج: `LLM_PROVIDER=model` مع `ANTHROPIC_API_KEY` (وبديل اختياري `GEMINI_API_KEY` و`GEMINI_MODEL`). النموذج يحوّل السؤال إلى عبارات بحث، ثم يكتب الجواب من المقاطع المسترجعة فقط ويسند كل جملة إلى رقم مقطع، ولا ينقل نص الآيات بنفسه: النص يُعرض حرفيًا في بطاقة المصدر. المدقق يرفض أي إسناد إلى مقطع لم يُسترجع وأي اقتباس لا يطابق المصدر، وعند أي خطأ يمتنع النظام.

نموذج مفتوح المصدر ومجاني على جهازك (مثل Qwen عبر [Ollama](https://ollama.com)): ثبّت Ollama ونزّل النموذج، ثم اضبط `OPENAI_COMPAT_BASE_URL=http://localhost:11434/v1` و`OPENAI_COMPAT_MODEL` باسم النموذج كما يظهر في `ollama list`. الطريقة نفسها تعمل مع خدمات مستضافة تتبع الصيغة ذاتها، مع `OPENAI_COMPAT_API_KEY`. عند خطأ مؤقت (مزدحم) يعيد النظام المحاولة مرة واحدة بعد ثانيتين. على جهاز بطيء: `MUHAWIR_PASSAGES=4` يرسل مقاطع أقل للنموذج، و`OPENAI_COMPAT_TIMEOUT=900` يطيل مهلة الانتظار بالثواني.

**أسلوب الحوار:** يحاور مُحاور السائل بلغة سهلة، ويجيب عن الاعتراضات بهدوء واحترام دون أن يصف السؤال بالفساد أو يحكم على السائل أو نيته. الرسالة التي فيها سخرية يُستخلص منها سؤالها بصياغة هادئة ويُجاب عنه من المصادر، والرسالة التي لا سؤال فيها تُقابَل بدعوة إلى السؤال لا بحكم. استُلهم هذا الأسلوب من طريقة كتاب «حوار مع صديقي الملحد» للدكتور مصطفى محمود (دار العودة) في عرض الاعتراض كاملًا ثم الجواب عنه بهدوء؛ ولا يُستعمل شيء من نص الكتاب أو حججه في الأجوبة، فالأجوبة من المصادر المعتمدة وحدها. لتجربة أسئلة حوارية متنوعة على الخادم العامل: `python scripts/try_questions.py`. ولمعرفة سبب عدم الإجابة عن سؤال: شغّل الخادم مع `MUHAWIR_DEBUG=1`، فيظهر السبب في الرد وفي سجل الخادم (دون نص السؤال).

**الأحاديث:** صحيح البخاري وصحيح مسلم بالعربية جزء من قاعدة البيانات (من بيانات hadith-api المفتوحة)، وتُعرض بالرقم المتداول مثل «صحيح البخاري، رقم 1»، ومع كل حديث رابط «تحقق في الدرر السنية» يفتح بحث الموسوعة الحديثية عنه. لإضافتهما إلى مجلد ملفات منزّل من قبل: `python -m muhawir.build_data --from-dir data/dumps --get-hadith`. البحث المباشر في الموسوعة الحديثية بموقع الدرر السنية متاح في الشيفرة لكنه مُطفأ افتراضيًا، لأن الموقع رفض الطلبات من الخادم (HTTP 403)؛ يُشغَّل بـ `MUHAWIR_DORAR=1` بعد إذن الموقع.

الإعدادات كلها في متغيرات بيئة (انظر `.env.example`). لا تُكتب المفاتيح في الشيفرة.

## بنية الشيفرة

| الملف | الدور |
|---|---|
| `muhawir/normalize.py` | توحيد النص العربي للبحث (الحركات والهمزات والتاء المربوطة) |
| `muhawir/corpus.py` | المصادر والمقاطع وفحص صحة ملف المقاطع، ولكل مصدر سطر يعرّف به |
| `muhawir/classify.py` | قواعد ثابتة توقف الحالة الشخصية (المستوى د) والحكم على الأشخاص ومحاولات تجاوز الضوابط |
| `muhawir/retrieve.py` | بحث BM25 بالكلمات، وفحص كفاية المقطع قبل أي جواب |
| `muhawir/generate.py` | المولّد: الاقتباس الحرفي، أو نموذج لغوي (Claude ثم Gemini احتياطيًا) بتعليمات ثابتة وإخراج JSON |
| `muhawir/verify.py` | المدقق: كل ادعاء يُسند إلى مقطع مسترجع، وكل اقتباس يطابق المقطع حرفيًا |
| `muhawir/sahihayn.py` | استيراد صحيح البخاري وصحيح مسلم بالعربية بالترقيم المتداول، بلا تعديل في النص |
| `muhawir/dorar.py` | البحث المباشر في الموسوعة الحديثية (الدرر السنية): قراءة النتيجة كما هي مع المصدر وحكم المحدث، دون تخزين |
| `muhawir/asbab.py` | عند السؤال عن سبب نزول لا يرد في كتاب أسباب النزول: يذكر ذلك صراحة مع اسم السورة أو الآية، ولا يدّعي أنه لا سبب لها مطلقًا |
| `muhawir/pipeline.py` | التسلسل: القواعد ثم الاسترجاع ثم التوليد ثم التدقيق ثم قراءة ثانية صارمة يتحقق فيها النموذج أن كل جملة يدل عليها مقطعها بالمعنى نفسه (وإن تعذرت لم يُعرض شيء) ثم بطاقة المصدر. في المحادثة يُعاد صياغة السؤال التابع (مثل «وما سبب نزولها؟») سؤالًا مستقلًا للبحث فقط، ولا يُجاب من المحادثة نفسها |
| `muhawir/quranpedia.py` | مستورد القرآن وموضوعات الآيات وكتاب تفسير من بيانات الموسوعة القرآنية، يحفظ النص حرفيًا مع الموضع ونسخة البيانات |
| `muhawir/store.py` | قاعدة SQLite للمقاطع والبحث (FTS5) بالواجهة نفسها، لتقليل الذاكرة |
| `muhawir/build_data.py` | تنزيل ملفات الموسوعة القرآنية وبناء القاعدة عند النشر |
| `muhawir/server.py` | واجهة HTTP (`/api/ask` و`/api/health`) والصفحة |
| `muhawir/static/index.html` | واجهة محادثة بالعربية والإنجليزية: إدخال بالصوت عبر خاصية التعرف على الكلام في المتصفح (Chrome وEdge وSafari)، وزر «استمع» يقرأ كلام مُحاور فقط دون نصوص الآيات والتفسير. المحادثة تبقى في الصفحة ولا تُحفظ على الخادم |
| `tests/` | الاختبارات، على البيانات المصطنعة فقط |

## تنبيه

مُحاور أداة تعريفية مسندة إلى مصادر معتمدة وليس مصدرًا للفتوى الشخصية. لا يملك النظام أهلية الحكم على واقعة فردية، ويحيل في ذلك إلى مختص.

---

**English summary.** Muhawir is an Arabic dialogue assistant that answers questions about Islam only from an approved source package, shows a source card with every answer, and abstains or refers to a qualified person when the evidence is insufficient. Built for the AI Challenge Serving Islamic Content (track 1). Status: preparation and initial scaffold. Any code written before the 4 October 2026 start is disclosed in docs/BASELINE.md.
