# التشغيل والاستمرار

ما يلزم لإبقاء مُحاور يعمل بعد التحدي: التكلفة، والاعتمادات، والصيانة، ومراجعة المحتوى، والمسؤوليات.

## مكونات التشغيل

| المكون | المزود | التكلفة | إن تعطّل |
|---|---|---|---|
| الخادم وقاعدة البيانات | Render، خطة `0.5c-512mb` المدفوعة (لا تنام) | سعر شهري ثابت؛ يُراجع في لوحة Render | الموقع لا يفتح؛ Render يعيد التشغيل تلقائيًا عند فشل فحص `/api/health` |
| النموذج اللغوي | Claude API (Anthropic)، النموذج `claude-sonnet-5-5` | بحسب الاستعمال، بسقف إنفاق شهري يضعه المشغّل في لوحة Claude | يقول مُحاور «الخدمة غير متاحة مؤقتًا»، ولا يعرض شيئًا غير متحقق منه |
| بيانات المصادر | الموسوعة القرآنية (quranpedia.net)، وhadith-api | مجانية | تُنزَّل عند كل نشر؛ إن تعذّر التنزيل فشل البناء وبقيت النسخة السابقة تعمل |

كل سؤال يستعمل ثلاث طلبات إلى النموذج: فهم الرسالة، وكتابة الجواب، والقراءة الثانية الصارمة. تكلفة السؤال الفعلية تُقاس من سكربت التقييم ومن صفحة الاستعمال في لوحة Claude، وتُسجَّل هنا بعد القياس.

## إيقاف الإنفاق المفاجئ

- سقف إنفاق شهري في لوحة Claude (Settings › Billing › Spend limits). عند بلوغه تتوقف الطلبات حتى بداية الشهر التالي أو رفع السقف، ولا تُحمَّل فاتورة إضافية.
- خطة Render بسعر ثابت.
- لا تُستعمل خدمات بحث خارجية مدفوعة. البحث في الدرر السنية مُطفأ افتراضيًا (`MUHAWIR_DORAR=0`) حتى إذن الموقع.

## الصيانة

| المهمة | متى | كيف |
|---|---|---|
| تحديث بيانات المصادر | شهريًا، أو عند إعلان الموسوعة القرآنية تصحيحات | إعادة النشر في Render؛ أمر البناء ينزّل أحدث النسخ (ترخيص الموسوعة يطلب إبقاء النسخ محدّثة) |
| متابعة الإنفاق | أسبوعيًا أثناء الاستعمال الكثيف | صفحة Usage في لوحة Claude |
| فحص الأعطال | عند تنبيه أو شكوى | سجل Render؛ يسجّل مُحاور سبب كل سؤال لم يُجب عنه دون نص السؤال |
| الاختبارات | قبل كل تعديل | `python -m pytest -q` |
| إعادة التقييم | بعد أي تعديل في القواعد أو النموذج أو المصادر | `python scripts/evaluate.py --runs 2 --baseline`، ومقارنة `docs/RESULTS.md` بالنتيجة السابقة |

## مراجعة المحتوى

- **قبل الإطلاق العام:** يراجع مختص شرعي قائمة التقييم والسلوك المتوقع فيها، ويملأ عمود «مراجعة بشرية» في `docs/RESULTS.md`.
- **أثناء التشغيل:** عيّنة دورية من الإجابات يراجعها مختص (مثلًا 20 إجابة شهريًا)، وتُصحَّح القواعد أو المصادر لا الإجابة وحدها.
- **المصادر:** لا يُضاف مصدر إلا بعد التحقق من أنه ضمن الحزمة العلمية للتحدي ومن حق استعماله، ويُسجَّل في [SOURCES.md](../SOURCES.md).
- **أذونات معلّقة:** الدرر السنية (البحث من الخادم)، والمستودع الدعوي (dawa.center). لا تُستعمل قبل الإذن.

## المسؤوليات

| الدور | المسؤول |
|---|---|
| الشيفرة والنشر والإنفاق | صاحب المشروع |
| مراجعة المحتوى الشرعي | مختص شرعي يُتفق معه (لم يُحدَّد بعد) |
| بيانات المصادر | أصحابها (الموسوعة القرآنية، hadith-api)؛ تُتابَع تحديثاتهم |

## البدائل عند تعطّل اعتماد حرج

- **النموذج:** يدعم مُحاور ثلاثة مزودين دون تغيير في الشيفرة: Claude، وGemini، وأي خادم بصيغة chat-completions (مثل Ollama بنموذج مفتوح المصدر). التبديل بتغيير متغيرات البيئة في Render.
- **الاستضافة:** أمرا البناء والتشغيل في `render.yaml` يعملان على أي استضافة Python بذاكرة 512 ميغابايت فأكثر.
